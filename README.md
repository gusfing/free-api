# 🆓 Free Public APIs

A curated collection of free APIs for developers.

## 📡 Available APIs

| API | Endpoint | Description |
|-----|----------|-------------|
| Anime Info | `/api/anime/{name}` | Get anime details |
| Movie Search | `/api/movie/{name}` | Search movies |
| Random Joke | `/api/joke` | Get random jokes |
| Weather | `/api/weather/{city}` | Get weather info |

## 🚀 Quick Start

```bash
# Just call the endpoint
https://api.example.com/api/joke
```
